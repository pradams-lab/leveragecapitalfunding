# Leverage Capital Hub

# Role and Objective

You are an elite, world-class frontend engineer, UX designer, and high-conversion web developer. Your task is to build an institutional-grade, high-trust, aggressive, and results-oriented corporate finance website for **Leverage Capital Funding**, tailored specifically for the Brazilian Merchant Cash Advance (MCA) market. 

The design must look polished, sophisticated, and completely professional—strictly avoiding anything that looks "vibe-coded," blocky, or cheap.

# Design & Aesthetic Guidelines

* **Vibe:** Institutional, high-trust, and aggressive. Zero BS. It should project absolute financial security, compliance, and speed.

* **Color Palette:** Deep charcoal and navy foundations, accented with crisp white typography and high-converting primary CTA elements.

* **Typography:** Elegant, modern financial-related font styles with precise tracking, generous spacing, and crystal-clear visual hierarchy.

* **Motion & Interactivity:** Incorporate smooth, subtle entry animations, hover states, and dynamic elements that enhance user experience without feeling cluttered.

* **Responsiveness:** Highly mobile-friendly, optimized for seamless conversion across all screen sizes.

# Content & Assets Instruction

* **Copy & Logo:** Extract all website copy, text elements, and the brand logo directly from the text file attached/uploaded to this prompt. Do not hallucinate or change the core messaging provided in that file.

* **Localization & Language Toggle:** The website must include an explicit, built-in language toggle option in the navigation bar allowing users to seamlessly switch between English (EN) and Portuguese (PT-BR) to guarantee absolute financial precision and local trust.

# Key Features & Requirements to Include

* **Sticky Navigation Bar:** Logo, core links (About, How It Works, Calculator, Testimonials), an explicit **Language Toggle (EN / PT-BR)**, and a high-contrast primary CTA button (*"Solicitar Capital"*).

* **Hero Section:** Aggressive value proposition focused on fast liquidity, clear trust badges (BBB accredited logo, Google 5-star review badge), a visible phone number tab (`+1 (774) 205-5547`), and an interactive preview or clean layout.

* **Social Proof / Credibility:** Animated metrics ribbon/marquee highlighting funding volume and compliance.

* **About Us Section:** Clear, direct messaging explicitly welcoming Portuguese-speaking entrepreneurs with zero bureaucracy.

* **How It Works:** A clear, elegant 3-step process broken down using polished card grids.

* **Interactive Funding & Repayment Calculator:** Sliders for requested advance amounts and terms to drive engagement.

* **Testimonials & Case Studies:** Verified review elements and success stories.

* **High-Converting Application / Contact Form:** Minimalist input form capturing essential details (Name, Company, Phone, Estimated Monthly Revenue) backed by security indicators.

* **Footer:** Comprehensive regulatory disclaimers, contact details (`+1 (774) 205-5547`), and trust seals.

Build the complete, fully responsive single-page or multi-page layout incorporating all the sections, styles, language switcher functionality, and data extracted from the uploaded text file and logo asset.
